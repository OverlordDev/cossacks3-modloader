# Changelog

## 0.1.0
- Подсказки и автодополнение по `modloader/api` игры (через Lua Language Server), обновляются вместе с игрой.
- Описания функций, которые создаёт сама DLL: `events`, `game`, `net`, `input`, `web`, `ui`, `gfx`, `savedata`, `native`, `mem`, `player`, `world`, `nation/unit/battle`.
- Проверка `manifest.lua`: id, стороны server/shared, multiplayer, существование файлов, опечатки в полях.
- Команды: «Создать мод», «Открыть modloader.log», «Указать папку modloader», «Открыть документацию».
- Сниппеты `cs3manifest`, `cs3event`, `cs3bind`, `cs3balance`, `cs3net`, `cs3hud`, `cs3button`, `cs3objects`, `cs3unit`, `cs3nation`.
