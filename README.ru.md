# Cossacks 3 Modloader

**Пишите моды для Казаков 3 на Lua, стройте интерфейсы на HTML и меняйте игру, не трогая её файлы.**

[🇬🇧 English](README.md) · 🇷🇺 Русский

📖 **[Сайт с документацией](https://overlorddev.github.io/cossacks3-modloader/)** · [English docs](https://overlorddev.github.io/cossacks3-modloader/en/)

> Пре-релиз. Windows, Steam-сборка 2.2.3 (игра 32-битная). Фанатский проект, никак не связан с GSC Game World.

## Зачем

Моды к Cossacks 3 «из коробки» пишутся на `.script`, Pascal-подобном языке, и чтобы поправить одну строку, обычно приходится класть в мод копию целого файла игры. Модлоадер подключается при запуске игры, и то же самое делается так:

```lua
-- крепкие мушкетёры для всех в партии
events.on("game.start", function()
    balance.setHP("musketeer18", 200)
    balance.setDamage("musketeer18", 40, 1)
    balance.set("musketeer18", "price[3]", 30)
end)
```

Поправили скрипт, набрали `.lua reload` в консоли модлоадера и видите результат без перезапуска игры.

## Что даёт

- **Моды на Lua 5.4:** события (`game.start`, `unit.death`, `unit.order` и др.), библиотека поверх игры (`state`, `units`, `buildings`, `balance`, `objects` и др.) и доступ к нативным функциям движка.
- **Интерфейсы на HTML/CSS/JS** (Chromium Embedded Framework) поверх игры: HUD, панели найма, меню или целые экраны, заменённые вашей страницей.
- **Замена файлов и патчи скриптов:** заменяйте файлы игры из папки мода или правьте в скриптах игры только нужные строки.
- **`content.lua`:** новые нации, юниты и исторические сражения (со своими картами) описываются данными.
- **Управление графикой:** пресеты пост-обработки, туман, тени, свет, небо.
- **Модели `.glb`:** кладёте модель, модлоадер сам распаковывает её в игру. Сейчас работают статические объекты, анимации в разработке.
- **Данные мода внутри сохранений** (`savedata`): состояние мода переживает сохранение и загрузку.
- **Проверки в сети:** хост сверяет, что у всех одинаковые игровые моды, а встроенный сторож сообщает о рассинхроне.
- **Инструменты разработчика:** консоль в игре, отчёты о сбоях со стеком, профилировщик, перезагрузка страниц при сохранении.

Файлы игры не меняются: всё происходит в памяти, так что запуск игры без лаунчера даёт обычных Казаков 3.

## Установка

**Из архива релиза.** Если на странице Releases опубликован zip, распакуйте его в папку игры и запускайте игру через `Cossacks3Launcher.exe`. Примеры модов в архиве выключены, включаются в меню **Insert** в игре.

**Из исходников:**

1. Соберите `Modloader For Cossacks 3.slnx` (Release, x86: игра 32-битная).
2. Скопируйте в папку игры `Cossacks3Launcher.exe`, `Cossacks3Loader.dll`, `Modloader For Cossacks 3.dll` (и `.pdb`, чтобы отчёты о сбоях были читаемыми) и `Cossacks3Cef.exe`.
3. Выполните `python tools/install_cef.py`, чтобы поставить CEF в `<игра>/cef`.
4. Скопируйте `api/` в `<игра>/modloader/api/`, а свои моды в `<игра>/modloader/mods/`.
5. Запускайте игру через `Cossacks3Launcher.exe`.

Сборка из командной строки:

```bash
MSBuild "Modloader For Cossacks 3.slnx" -t:"Modloader For Cossacks 3" -p:Configuration=Release -p:Platform=x86
```

Лаунчер запускает игру приостановленной, внедряет загрузчик и только потом пускает игру, поэтому замена файлов, патчи скриптов и шейдеры работают с самого первого чтения файла.

## Первый мод

Мод это папка в `<игра>/modloader/mods/` с файлом `manifest.lua`:

```lua
return {
    id = "hp_report",
    name = "HP Report",
    version = "1.0.0",
    client = "client.lua",
    multiplayer = "optional",
}
```

Выберите сторону: `client` (интерфейс и клавиши, у каждого игрока), `server` (решения хоста) или `shared` (правила, которые должны быть одинаковыми на всех машинах, например баланс).

- Быстрый старт: [MODDING.md](MODDING.md)
- Полный справочник API: [AI_MODDING_REFERENCE.md](AI_MODDING_REFERENCE.md) (написан так, чтобы его можно было отдать нейросети, которая пишет моды) · [на сайте](https://overlorddev.github.io/cossacks3-modloader/core-rules.html)
- Подробная документация: [DOCUMENTATION.md](DOCUMENTATION.md)
- Примеры: [`examples/mods/`](examples/mods): баланс, HUD, своё главное меню, графика, новые нации и юниты, патчи, сохранённые данные.
- **Расширение для VS Code:** автодополнение по всему API, проверка манифеста и генератор модов: [ветка `vscode-extension`](https://github.com/OverlordDev/cossacks3-modloader/tree/vscode-extension).

## Структура репозитория

| папка | что |
|---|---|
| `Modloader For Cossacks 3/core/` | основная DLL (C++): хуки, Lua, CEF, события |
| `Launcher/`, `Loader/` | запуск игры и маленький загрузчик |
| `CefSub/`, `CefWrapper/` | процесс Chromium и обёртка libcef |
| `api/` | Lua-библиотека, копируется в `<игра>/modloader/api` |
| `builtin/` | компоненты, встроенные в модлоадер (сторож рассинхрона) |
| `examples/mods/` | примеры модов |
| `tools/` | генераторы справочников (IDA, скрипты игры), тесты api, упаковщик релиза |
| `external/` | Lua, Dear ImGui, MinHook, CEF |

## Известные ограничения

- Моды, меняющие геймплей, должны быть одинаковыми у всех в сетевой партии (`shared`, `multiplayer = "required"`).
- Отменять `unit.order` в сети безопасно только одинаково на всех машинах.
- Новые карты и файлы, которых игра сама не перечислила, не подхватываются (перечисление папок не перехватывается).
- Шейдеры и часть ресурсов читаются один раз при старте, после замены нужен перезапуск.
- Проверка модов и неизменность контрольной суммы лобби ещё не проверены в реальной сетевой игре.
- CEF работает в потоке игры, поэтому тяжёлая страница замедляет игру.

## Обратная связь
