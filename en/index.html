An example in a minute

input.bind("F7", function()
    if not game.isInGame() then return end
    local me = native.GetPlayerIndexInterfaceIO()
    local total, count = 0, 0
    for _, h in ipairs(objects.list(me)) do
        local o = objects.read(h)
        if o and not o.bdead then total, count = total + o.hp, count + 1 end
    end
    log.info(string.format("objects: %d, total HP: %d", count, total))
end)

end)
net.on("give_gold", function(data, from)
    local who = game.playerIndexOf(from)
    local amount = math.min(tonumber(data and data.amount) or 0, 1000)
    player(who):add("gold", amount)
    net.broadcast("gold_given", { player = who, amount = amount })
end)

FAQ

How do I install the modloader?+
  1. Build the solution Modloader For Cossacks 3.slnx (Release, x86).
  2. Copy Cossacks3Launcher.exe, Cossacks3Loader.dll, the main DLL and Cossacks3Cef.exe into the game folder.
  3. Install CEF: python tools/install_cef.py.
  4. Copy api/ to <game>/modloader/api/, mods to modloader/mods/.
  5. Launch through Cossacks3Launcher.exe.
Where do mods go?+

<game>/modloader/mods/<mod folder>/ — it must contain manifest.lua. A mod can be data-only: just assets/, patches/ or content.lua.

How do I edit the api without rebuilding?+

The api/*.lua files live separately from the DLL: edit a file, then run .lua reload in the modloader console.

What goes on the client and what on the server?+

Interface and keys — client. Host decisions — server. Anything that changes the world identically on all machines (balance, stats, logic) — shared: otherwise the match desyncs online. More — which side can do what.
