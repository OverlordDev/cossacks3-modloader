Game screens

Generated by tools/gen_screens.py from data/gui/menu.inc. Do not edit by hand.

A screen = Show<Name> (builds it) + Event<Name> (buttons). Work with them through screens.* (api/15_screens.lua).

The Show/Hide/Close tags (8001–8003) exist on every screen that has an Event state.
