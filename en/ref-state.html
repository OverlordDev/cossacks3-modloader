Game state

Generated by tools/gen_game_api.py from data/scripts/lib/classes.script. Do not edit by hand.

Any field is read the same way from Lua and from pages:

state.get('gProfile.sndmaster')       -- 0.75
state.read('gMap.players[0]')          -- the whole record as a table
state.set('gProfile.sndmaster', 0.5)   -- server/console only
G.gMap.settings.gen.mapsize            -- the same, with dots
