# format_probe — проверка формата .oss в игре

Модели крестьян (`data/actors/units/pea*.oss`) изменены двумя способами:

1. **Вершины с x > 0 растянуты втрое** — у крестьянина «нос» (длинный вырост) в сторону +X модели.
   Смотри, куда он направлен, когда крестьянин **идёт**:
   - вперёд по ходу → «вперёд» модели = +X;
   - вбок → «вперёд» = ±Y;
   - назад → «вперёд» = −X.
2. **Все UV в одной точке** — крестьянин одного цвета. Сравни цвет с таблицей
   (освещение сделает его темнее/светлее, важно — какой из двух похож):

| нация | UV-точка (u, v) | цвет, если V читается как есть | цвет, если V перевёрнут (1 − v) |
|---|---|---|---|
| Россия | 0.719, 0.234 | светло-коричневый #ad714b | почти чёрный #080808 |
| Украина | 0.469, 0.781 | рыже-коричневый #4f2d1b | нейтрально-серый #787574 |
| Турция | 0.875, 0.109 | серый #8b8b90 | почти чёрный #1e1610 |
| Англия | 0.141, 0.125 | коричнево-бежевый #726143 | чёрный #050505 |
| Шотландия | 0.641, 0.422 | охра #836639 | почти чёрный #0f0e0c |
| Испания | 0.750, 0.281 | бежево-коричневый #92735b | тёмно-коричневый #371a09 |
| Польша | 0.578, 0.391 | серый #555452 | тёмно-коричневый #1a1613 |
| Австрия | 0.609, 0.328 | тёмно-коричневый #361c09 | серо-коричневый #4f443a (слабый контраст) |

«Как есть» — строка текстуры считается от верхнего края картинки DDS (v = 0 — верх).
Лучше проверять Россией, Украиной или Турцией — там контраст сильнее всего.
Цвет игрока может подмешаться, если в этой точке альфа текстуры не 0.
